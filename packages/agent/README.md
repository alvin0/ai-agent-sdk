# @ai-agent-sdk/agent

Runtime: **Universal** (Edge/Worker, browser, Deno, Bun, and Node).

```sh
pnpm add @ai-agent-sdk/core @ai-agent-sdk/agent
```

Universal agent definitions, bounded model/tool loops, memory and compaction, skill contracts, team orchestration, and canonical per-run accounting.

This package depends only on `@ai-agent-sdk/core` and is designed for browser, Edge/Worker, and Node runtimes. Filesystem skills and other Node capabilities live in separate packages.
